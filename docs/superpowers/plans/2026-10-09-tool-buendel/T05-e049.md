**Regel:** Eine Instanz der Rollenklasse `Leads` gilt als **herausgerechnet**, wenn ihr erster Prompt (Briefing) im **Kopfblock** — die ersten `BUDGET_LINES = 10` Zeilen — eine Zeile `Budget: keins` trägt (Gross-/Kleinschreibung egal, Markdown-Präfixe `-`, `*`, `**` erlaubt; Rest der Zeile beliebig, z. B. „keins, keine Agenten starten“). Andere Rollenklassen und andere Budgetzeilen (`Budget: 1 Start …`, `Budget: 0`) zählen nicht (konservativ, E-049 „Messbarkeit“).

- `steuerung_heraus` = Kostenanteil der herausgerechneten Lead-Instanzen am Gesamtgewicht;
- `steuerung_bereinigt` = `steuerung` − `steuerung_heraus` (gleicher Nenner, Gegenprobe roh = bereinigt + herausgerechnet exakt);
- `steuerung_heraus_n` = Zahl dieser Instanzen.

**Ausgabe:** eine Zeile direkt **nach** den Ampelzeilen, **ohne** Ampel-Präfix (`- ROT:` würde einen Vorfall über `effort.parse_ampel_session` auslösen):

```text
- Steuerungsanteil bereinigt (E-049, ohne 2 Lead-Instanzen mit „Budget: keins“): 41.7 %, Bewertung gelb (Schwellen wie die Rohzeile; herausgerechnet 17.6 %; roh = bereinigt + herausgerechnet)
```

**Interfaces:**

- Produces: Schlüssel `steuerung_bereinigt: float`, `steuerung_heraus: float`, `steuerung_heraus_n: int` im Ergebnis von `efficiency.compute`; Feld `budget_none: bool` je Instanz und je Zeile in `lead_stats.rows`; Konstanten `BUDGET_LINES = 10`, `BUDGET_NONE` (Regex).
- Consumes: bestehende `role_class`, `ampel`, `_pct`, `_ratio`.

BUDGET_LINES = 10  # Kopfblock des Briefings (E-049, R420 V2)
BUDGET_NONE = re.compile(r"^[\s>*#-]*(?:\*\*)?Budget:(?:\*\*)?\s*keins\b", re.IGNORECASE | re.MULTILINE)


def _budget_none(prompt: str | None) -> bool:
    head = "\n".join((prompt or "").splitlines()[:BUDGET_LINES])
    return bool(BUDGET_NONE.search(head))
