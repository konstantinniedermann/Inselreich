# Lizenztexte

Hier liegen die vollständigen Lizenztexte der fremden Assets, die in [`../CREDITS.md`](../CREDITS.md)
aufgeführt sind (Regeln: [ADR-006](../adr/ADR-006-offene-lizenzen.md)).

## Ablage-Konvention

- Je Lizenz eine Datei mit dem Lizenztext im Wortlaut, benannt nach Kennung und Version, z. B.
  `CC-BY-4.0.txt`, `CC0-1.0.txt`, `MIT.txt`, `OFL-1.1.txt`.
- Autoren-spezifische Hinweise (Copyright-Zeile, geforderter Attributionstext) stehen in
  `<asset>-NOTICE.txt`.
- Jeder Eintrag in `CREDITS.md` verweist auf die passende Datei.
