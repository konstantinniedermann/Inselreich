# ADR-004: Eigener Titel, eigene Grafik, eigene Spielwerte

Status: akzeptiert · Datum: 2026-09-29

## Kontext
„Anno 1602" ist eine geschützte Marke mit urheberrechtlich geschützten Grafiken, Sounds und
Texten. Spielmechaniken als solche sind nicht geschützt.

## Entscheidung
- Titel „Inselreich". Keine Übernahme von Grafiken, Sounds, Texten oder Balancingtabellen.
- Grafik wird prozedural im Code gezeichnet; Zahlen werden selbst gesetzt und balanciert.
- Allgemeine Begriffe (Kontor, Holzfäller, Siedler) sind frei verwendbar.

## Konsequenzen
- Repo kann gefahrlos öffentlich gemacht werden.
- Kein Asset-Import-Workflow nötig.
